# ScanWise Non-Goals

ScanWise version 1 will not attempt to become:

- a general-purpose antivirus;
- a browser;
- a camera replacement;
- a full password manager;
- an enterprise inventory platform;
- a payment processor;
- a product-price comparison service;
- an OCR/document scanner;
- a social network;
- a generic AI assistant;
- a cloud collaboration tool.

## Security limitations

ScanWise performs local structural checks.

It cannot reliably determine:

- whether a website currently hosts malware;
- whether a domain has been compromised;
- whether a shortened URL redirects to a safe destination;
- whether a product is genuine;
- whether a payment recipient is legitimate;
- whether encoded contact information belongs to the claimed person.

The UI and documentation must communicate these limitations responsibly.

## Product discipline

A proposed feature should be rejected or deferred when it does not improve:

- understanding;
- informed action;
- privacy;
- organization;
- reuse;
- operational reliability.
